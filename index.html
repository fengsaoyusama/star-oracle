数据源设置

默认使用本地星象算法，离线也能用。想接真实运势接口，就选一个在线源；请求失败会自动回退本地，不会白屏。

AppKey 只保存在你自己的浏览器里。如果浏览器被跨域拦截，会自动回退本地数据。

支持 ShowAPI 风格 showapi_res_body.day，或简化字段：overall / love / career / money / luckyColor / luckyNum / luckyTime / luckyDir / luckyStar / notice / tip。

在线数据只补充运势指数与幸运项；宜忌、配对、星签仍由本地生成。接口失败不会影响正常使用。
